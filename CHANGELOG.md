# Changelog

All notable changes to GeoQibla are documented here.

## Unreleased

## 0.0.2

- Redesigned the default Qibla screen with an animated compass rose and Kaaba marker.
- Improved compact-width sizing, state presentation, and status details.
- Added a project README styled for GitHub discovery.
- Added reusable GeoQibla icon assets for docs and launcher usage.
- Added GitHub issue and pull request templates.

## 0.0.1

- Initial Maven Central release.
- Added `GeoQiblaScreen`, `rememberQiblaController`, controller state models, configuration, styling, localization, and slot APIs.
- Added Android and iOS platform services for location and heading.
